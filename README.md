# Company Relational Database Schema & Querying

A complete PostgreSQL relational database implementation featuring primary/foreign key relationships, junction tables for Many-to-Many entities, and multi-table complex `JOIN` queries.

## 🌟 Database Schema Features
- **Tables Designed:** `department`, `employee`, `employee_profile` (1-to-1), `project`, and `employee_project` (Many-to-Many junction table).
- **Constraints Applied:** Primary Keys, Foreign Keys, `UNIQUE` constraints, and Self-Referencing Manager Keys.
- **Queries:** Multi-table `JOIN` operations retrieving unified records for employees, salaries, projects, and departments.

## 🛠 Tech Stack
- **Database Engine:** PostgreSQL
- **Language:** SQL (DDL, DML)
